# Response Format Rules

So soll der Agent seine Antworten und Zusammenfassungen an den Nutzer formatieren:

*   **Kompaktheit:** Halte Zusammenfassungen und Übersichten kurz, prägnant und fokussiert. Vermeide weitschweifige Erklärungen, es sei denn, sie sind für die technische Entscheidung notwendig.
*   **Pfad-Angaben:** Gib bei jeder geänderten, erstellten oder referenzierten Datei immer den exakten Pfad an (z. B. `server/server.js`), idealerweise als klickbaren Link formatiert.
*   **Kategorisierung:** Trenne in deinen Übersichten am Ende der Antwort klar zwischen:
    *   **NEU:** Dateien, die komplett neu angelegt wurden.
    *   **ERWEITERT / MODIFIZIERT:** Bestehende Dateien, die angepasst wurden.
*   **Struktur:** Verwende Listen (Bullet Points) für eine schnelle und einfache Lesbarkeit.
